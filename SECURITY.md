# Security policy

## Reporting a vulnerability

Report suspected vulnerabilities privately to
[albond.dev@proton.me](mailto:albond.dev@proton.me), with the subject
"Locked Gaze security report". Please do not disclose an unpatched
vulnerability in a public issue.

Include the app version, macOS version, a description of the impact, and
minimal reproduction steps. Use synthetic examples. Do not send camera
recordings, credentials, signing keys, or unrelated personal information.

The maintainer will review reports and coordinate a fix and disclosure
where appropriate. There is no guaranteed response time or paid bug bounty.

## Supported versions

Version 1.0.0 is in preparation. After release, security fixes are intended
for the latest stable version; older versions may require an update.
