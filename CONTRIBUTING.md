# Contributing

Locked Gaze aims to stay small, lightweight, and reliable. Focused bug fixes,
accessibility improvements, and stability work are welcome. Discuss new
features before investing in a large change.

## Report a problem

Use [GitHub Issues](https://github.com/albond/locked-gaze/issues). Include:

- App version, macOS version, and Mac chip.
- Camera type and the video application involved.
- Steps to reproduce, expected behavior, and what happened instead.

Remove personal information from logs and screenshots. Prefer synthetic
examples over recordings of people. Report security issues privately as
described in [SECURITY.md](SECURITY.md).

## Propose a change

Keep each pull request focused, explain its user-visible effect, and include
relevant verification. Camera or permission changes need checks for denial,
cancellation, reconnection, and repeated activation. Do not claim support for
hardware or macOS versions that you have not tested.

Use English for code, documentation, and interface text. Preserve applicable
copyright notices. Only contribute material you have the right to submit.
Contributions to MIT-covered code are provided under the project's
[MIT License](LICENSE). Third-party material must retain its own license.

Do not include model weights, compiled models, personal camera frames,
credentials, or signing material in a pull request.

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
