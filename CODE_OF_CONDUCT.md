# Code of conduct

Be respectful and constructive in project discussions, issues, and pull
requests. Critique ideas and code without attacking people. Welcome different
backgrounds and levels of experience.

Harassment, threats, discriminatory remarks, sexualized comments, spam, and
sharing another person's private information without consent are not
acceptable.

Report concerns privately to
[albond.dev@proton.me](mailto:albond.dev@proton.me).
The maintainer may remove harmful content, close disruptive discussions, or
restrict participation. Reports will be handled with discretion; information
will be shared only as needed to address the concern.

This policy applies to project spaces and to conduct while representing the
project publicly.
